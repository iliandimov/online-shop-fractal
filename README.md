# Forme — онлайн магазин

Проектът използва Laravel 12, Lunar 1.5, Filament 4 и Spatie Laravel Media Library 11 с MariaDB.

## Състояние

Има български UI прототип за начална страница, категории, продуктова страница, количка, checkout с наложен платеж и потвърждение. Категориите и продуктите вече се четат от Lunar в MariaDB. Количката е в сесия и използва реални варианти/SKU и наличности; потвърдените поръчки се записват през Lunar в MariaDB.

Lunar е инсталиран в MariaDB базата `fractal_ecommerce`. Административният панел е на `/lunar`. Създаден е администратор `admin@fractal.local`; смени временната парола при първото влизане.

Началните настройки са EUR, български език и показване на цените с включено ДДС. Данъчните ставки още не са конфигурирани; това ще уточним със счетоводител преди реални продажби.

## Локална среда

Нужни са PHP 8.4+, Composer, Node.js 20+ и MariaDB. При WSL:

```bash
php8.4 artisan serve
```

Laravel се свързва към MariaDB чрез `.env`. Не добавяй `.env` или реални API ключове в Git.
